# Alumni Chronicle

I want you to create an AWARD-WINNING, PREMIUM, highly interactive School Alumni Meet Event Invitation webpage.

This is a COMPETITION PROJECT. Seven students are creating event invitation pages and only the BEST UI/UX design will be selected.

Therefore, DO NOT create a basic HTML invitation.

DO NOT create a generic landing page.

DO NOT create a simple card with text.

Create something that immediately gives a "WOW" impression when opened.

==================================================

CORE CONCEPT

==================================================

Create a sophisticated TWO-PAGE DIGITAL INVITATION CARD.

The desktop screen should look like a beautifully designed physical invitation card opened in the center:

        ┌─────────────────┬─────────────────┐

        │                 │                 │

        │    LEFT PAGE    │   RIGHT PAGE    │

        │                 │                 │

        │   VISUAL        │   INFORMATION   │

        │   + EMOTION     │   + RSVP        │

        │                 │                 │

        └─────────────────┴─────────────────┘

The invitation should feel like a premium luxury event invitation mixed with modern interactive web design.
